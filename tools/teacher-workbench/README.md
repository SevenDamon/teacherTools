# 班级工作台

版本：`v1.3.2`

一个可直接在浏览器运行的单文件班级管理工具，适合在教室电脑中离线使用。

## 主要功能

- 课表管理
- 学生花名册导入
- 拖拽排座与随机排座
- 学生分组
- 考勤点名
- 作业提交统计
- 班级数据分析
- “书声琅琅耀星河”和“快乐星球点名”趣味活动
- 自动备份、手动导出与导入恢复

## 使用方法

1. 下载本目录中的 `index.html`。
2. 双击文件，使用 Chrome 或 Edge 打开。
3. 进入“排座系统”，导入学生花名册。
4. 使用一段时间后，通过“导出备份”保存长期备份。

## 数据说明

学生和班级数据保存在浏览器本地，不会由本工具上传到网络。在线版、本地版、不同浏览器和不同电脑之间的数据互不相通，迁移时需要导出和导入备份。

## 隐私提醒

请勿上传含有真实学生姓名、考勤、作业或成绩信息的备份文件。反馈问题时建议使用虚构姓名或清空数据后的截图。

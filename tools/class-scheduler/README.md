# 排课工作台 v2.8

面向学校年级排课的浏览器工具。无需后端服务，数据默认保存在当前浏览器中。

## 在线使用

[打开排课工作台](https://sevendamon.github.io/teacherTools/tools/class-scheduler/)

## 主要功能

- 按年级配置班级数、课程和周课时
- 从 Excel 导入教师任课信息，并导出排课结果
- 自动排课、固定课、单格锁定、教师整组锁定和手工调整
- 主科名单可按学年修改，相关优先级、颜色、统计和规则随名单变化
- 可选“主课后固定跟一节自习”：自习沿用同一位老师，两个课位成对锁定
- 检查未排课程、规则冲突、教师供需短缺、体育第一节和主科末两节
- 右上角“作者”入口展示“科学老师学AI”的公众号与微信二维码

## 使用方式

在线版直接打开上方链接。需要离线使用时，下载 [`class-scheduler-v2.8.html`](./class-scheduler-v2.8.html)，再用 Chrome 或 Edge 打开。

首次使用建议先在“设置”中完成以下检查：

1. 核对每天课时结构和各年级班级数。
2. 核对每个年级的课程与周课时。
3. 在“规则”中选择本学年实际认定的主科。
4. 导入教师名单后，检查页面显示的供需短缺和冲突数量。
5. 生成后先人工复核，再作为正式课表使用。

## 关于“主课后跟自习”

该规则是硬规则。每节被选中主科会连带占用下一节普通课位作为自习，自习教师与主课教师相同，两个格子一起锁定。它不能跨天，也不会占用早读或晚自习。

这项规则最容易在总课位不足时失败。主课数量较多、固定课较多或教师跨班较多时，其他课程可能无法排入。工具会把无法满足的情况列入冲突清单；不要仅以“已生成”为排课完成标准。

## 文件说明

- `index.html`：GitHub Pages 在线入口
- `scheduler-core.js`：排课与规则校验逻辑
- `scheduler-app.js`：页面交互、数据导入导出和本地存储
- `xlsx.full.min.js`：Excel 文件处理依赖
- `class-scheduler-v2.8.html`：内嵌依赖和作者图片的离线单文件版
- `assets/`：作者信息入口使用的公开二维码图片
- `LICENSES/`：第三方依赖许可证

## 数据与隐私

教师名单、班级和课表数据默认仅保存在浏览器本地。请勿把含真实姓名、联系方式或校内排课信息的导出文件提交到公开仓库。

# 教师工具箱 TeacherTools

一组面向一线教师的轻量化教学工具。无需安装、无需登录，下载单个 HTML 文件即可在教室电脑中运行。

## 已发布工具

### 班级工作台

将课表、排座、学生分组、考勤、作业提交、统计分析和趣味学习整合在一个本地网页中。

- [在线体验](https://sevendamon.github.io/teacherTools/tools/teacher-workbench/)
- [查看源码与使用说明](./tools/teacher-workbench/)
- 下载方法：打开工具目录中的 `index.html`，点击右上角下载按钮保存文件

### 排课工作台

按年级管理教师、课程和排课规则，支持自动排课、固定课、锁定、冲突检查、手工调整以及 Excel 导入导出。

- [在线使用](https://sevendamon.github.io/teacherTools/tools/class-scheduler/)
- [查看源码与使用说明](./tools/class-scheduler/)
- [下载离线单文件版](./tools/class-scheduler/class-scheduler-v2.8.html)
- 当前版本：v2.8
- 规则提醒：“主课后固定跟自习”会让每节主课额外占用一节普通课位，启用前必须核对总课位

## 为什么是单 HTML

- 双击即可使用，不需要安装软件或配置服务器
- 工具、样式和必要图片均保存在一个文件中
- 方便使用 U 盘、网盘或聊天工具备份和迁移
- 断网后仍可使用主要功能

## 数据与隐私

班级数据默认保存在当前浏览器的本地存储中，不会上传到本仓库。更换电脑、浏览器或从在线版切换到本地版时，请先在工具内导出备份，再在新环境中导入恢复。

请勿把含有真实学生数据的备份 JSON 提交到公开仓库。

## 使用方式

1. 打开工具目录，下载其中标明的单文件版本；在线部署版可能由多个文件组成。
2. 可将文件重命名为便于识别的中文名称。
3. 使用 Chrome 或 Edge 浏览器打开。
4. 首次使用后导入学生花名册，并定期导出备份。
